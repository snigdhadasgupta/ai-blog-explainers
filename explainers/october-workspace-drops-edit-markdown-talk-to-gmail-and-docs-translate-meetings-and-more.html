October Workspace Drops

Google's October Workspace update leans into AI-assisted, voice-driven, multilingual work: native Markdown editing in Docs and Drive, conversational voice in Gmail and Docs, real-time speech translation in Meet across 63 languages, and faster migration off Microsoft 365.

The idea in five lines

  • Markdown is now native — preview, edit, and co-edit .md files directly in Docs and Drive, with real-time comments and version history.
  • Talk to Gmail and Docs — Gmail Live answers questions about your inbox; Docs Live turns spoken brainstorms into briefs and memos, grounded in your email, chat, and Drive.
  • Meet translates 63 languages live — Gemini 3.5 Live Translate renders speech and captions into each attendee's language, toggled per person.
  • Meetings close themselves out — Quick notes default to a one-page summary, and one post-call click drafts follow-ups and syncs action items to Tasks.
  • Leaving Microsoft 365 got easier — Teams, OneDrive, and SharePoint migration runs up to 5x faster at no added cost (a vendor claim with no baseline).
So what for you

If your teams prompt AI or write docs in Markdown, native .md editing removes the file-conversion shuffle — and the live-translation and voice features are worth piloting with distributed teams before a wide rollout. Read the 5x migration figure as a vendor claim; validate it on your own data before planning a cutover.

The details

What actually ships, and where

Markdown support adds a .md badge in the document header, full co-editing with comments and version history in Docs, and native previews in Drive. Gmail Live lets you ask questions of your inbox ("what are the key points for this morning's meeting?"); Docs Live, powered by Workspace Intelligence and grounded in your email, chat, and Drive, turns spoken brainstorms into briefs, executive summaries, or client strategy memos. Meet translation is built on Gemini 3.5 Live Translate.

Migration data import covers Teams to Google Chat (channel history, DMs, attachments, spaces), OneDrive to Drive (files, nested folders, permissions), and SharePoint Online to shared drives (libraries, permissions, metadata). Office Editing Mode opens Office attachments from Gmail, with improved cross-references in Docs and better charts and pivot tables in Sheets. Everything is rolling out to Workspace customers now.

Worth a pilot

Turn on native Markdown for teams that already prompt AI, try live translation in a recurring distributed meeting, and pressure-test the 5x migration claim on a real mailbox before committing to a Microsoft 365 cutover.
