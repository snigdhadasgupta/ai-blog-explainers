One Claude Memory, Everywhere You Work

Starting today, the memory you use in chat is the same one Claude uses in Cowork. Wherever you work, Claude starts from what it already knows about you — and you can see, edit, or delete any of it, topic by topic.

The idea in five lines

  • One memory across surfaces — What Claude remembers in chat is now there in Cowork and vice versa — less re-explaining, more picking up where you left off.
  • Updates as you chat — Claude adds topics during a conversation instead of summarizing after it ends; say a deadline moved and the next chat already knows.
  • You can read and edit it — Every memory is a short file under Topics in settings; fix your company's old name once and every future conversation gets it right.
  • Sensitive topics off by default — Claude won't store health, beliefs, or politics unless you turn it on; some data — SSNs, criminal history, immigration status — is never stored.
  • Admins control the enterprise — Memory is on by default on Free, Pro, and Max; for Team and Enterprise, admins decide availability and it's off until a user turns it on.
So what for you

Treat memory as a shared brief you maintain, not a black box. Spend two minutes in Settings → Memory to review what Claude has saved, correct anything stale, and decide whether a sensitive-but-useful fact is worth turning on — because a correction in one file propagates to every conversation after it.

What changed

Context you built in chat now shows up in Cowork

Cowork now has memory, and it's the same one you use in chat. When Cowork runs a task in the cloud, what Claude learned from your chats is there — and what comes up in Cowork carries back to chat. Ask Cowork to draft an update for your manager and it already knows who that is and how she likes updates written; brainstorm a conference agenda in chat and the budget doc Cowork builds knows the headcount, city, and speakers.

Explain once how your team defines its metrics, and every quarterly review deck Cowork builds after that uses them, with no rebriefing.

How it learns

Memory updates live, and you can see all of it

Claude now adds topics to memory as you chat, rather than summarizing conversations after they end. Mention that a deadline moved to September and your next conversation knows without you saying “remember this.” Everything Claude remembers sits in a list of short files under Topics in Memory settings, where you can read, edit, or delete each one. You can pause or reset memory at any time.

The privacy model

You decide what counts as sensitive

By default, Claude does not store personal or sensitive subjects — health, race, ethnicity, religion, politics, gender identity. But what some consider sensitive, others find useful: turn on “include sensitive topics in memory” and Claude will remember, say, a gluten allergy when suggesting recipes. Saving is forward-only (nothing retroactive), you get a notice each time, and you can turn it off anytime.

Getting started

Memory is on by default on Free, Pro, and Max across web, desktop, and mobile; saving sensitive topics is off by default. Team and Enterprise admins control availability. Visit Settings → Memory to turn it on and control what Claude remembers.
