The Builder’s Guide to GPT-5.6

OpenAI’s field notes from startups in production: smarter model selection and new Responses API primitives make frontier-level agents dramatically cheaper — sometimes matching last generation’s quality at a fraction of the cost.

The idea in five lines

  • Frontier agents got much cheaper — GPT-5.6 pushes more capability into lower reasoning efforts; on Agents’ Last Exam, Sol at “low” beat 5.5 at “high” with the same harness.
  • Right-size the model — smaller Luna and Terra now rival last-gen flagships — one team kept 98% of extraction accuracy at 1/18th the cost; Luna hit 84% on BrowseComp for $1.33 vs $33 before.
  • Reuse work across turns — persisted reasoning plus native compaction let agents hold coherence over long tasks; on ARC-AGI-3, Sol jumped from 13.3% to 38.3% using ~6× fewer output tokens.
  • Move deterministic work into code — Programmatic Tool Calling lets the model orchestrate tools in JavaScript outside its context window, so tokens go to judgment (one team cut input tokens 21%).
  • Tune caching and multi-agent — a 30-minute cache TTL and deterministic breakpoints lift hit rates; native multi-agent parallelizes work when spawning subagents actually pays off.
So what for you

If you’re building on LLMs, stop defaulting to the biggest model at max reasoning — test a smaller model at a tuned reasoning effort on your real tasks, and push deterministic filtering and aggregation into code so you only pay frontier prices for actual judgment.

A better deal out of the box

More capability, fewer tokens, lower effort

Each generation since GPT-5 has tackled longer-horizon tasks with fewer tokens, and GPT-5.6 continues the trajectory with minimal harness changes. The notable shift is accuracy at lower reasoning efforts: on Agents’ Last Exam, GPT-5.6 Sol at “low” reasoning outperformed GPT-5.5 at “high” with the harness held constant.

“We dropped GPT-5.6 into our harness, and low reasoning effort gave us our best results — it got to the right answer with fewer tokens.” — Izzy Miller, Hex

Programmatic tool calling & caching

Reserve model tokens for judgment

Agentic work splits into tasks that need judgment and work that mostly moves, filters, and combines data. Programmatic Tool Calling lets GPT-5.6 write JavaScript to orchestrate tools, run independent calls in parallel, and process outputs outside its context window — so the model focuses on what requires intelligence. Rogo reported matching its rubric quality while using 21% fewer input tokens.

Across the family, the prompt-cache TTL was extended to a 30-minute minimum and cache breakpoints can now be set deterministically. One team (Ploy) added breakpoints and workspace-specific keys to a shared 29,000-token prompt and cut uncached input by 28%.

The economics of agents changed

Use cases that once needed a frontier model at every step can now match or beat that quality at a fraction of the cost — by using smaller models, tuning reasoning effort, and making efficient architectural choices.
