Easier Microsoft 365 → Workspace Migration

The move off Microsoft 365 usually stalls on two fears: losing data in transit and breaking the people who still live in Office. Google’s update targets both — faster, label-preserving migration plus Office files that stay editable in Workspace.

The idea in five lines

  • Migrate up to 5x faster — the cloud-native data import service now moves Exchange Online, SharePoint, OneDrive, and Teams into Gmail, Drive, and Chat at no extra cost. Generally available now.
  • Security survives the move — coming by year-end, import preserves Microsoft Information Protection (MIP) sensitivity labels and encrypted email, mapping MIP labels to Workspace equivalents in the Admin Console.
  • Office files stay editable — open Office attachments in Gmail, edit in Docs/Sheets/Slides, and Gmail auto-drafts a reply with the updated file — no download, rename, re-upload.
  • Sheets closes the Excel gap — high-fidelity pivot tables, combo and multi-X scatter charts with no formatting loss, a manual-calculation mode, and cell capacity doubled to 20 million.
  • Keep your meeting rooms — a native Google Meet experience runs on existing Cisco hardware before year-end, pairing Cisco AI with Gemini in Meet and keeping Webex/Teams/Zoom reachable.
So what for you

If a Workspace move is on your roadmap, the practical unlock is that you no longer have to re-classify data by hand or rip out Cisco meeting rooms — and users on the other side can keep working in Office files during the transition. Pilot the data import tool in the Admin console and test MIP-label mapping before you commit to a cutover date.

Why it matters

Migrations stall on data loss and user disruption

Two things usually slow a Workspace rollout: IT’s fear of losing or mishandling sensitive data in transit, and the drag of users who still depend on Microsoft files and meeting habits. Google’s update is aimed squarely at both — a faster, security-aware import path for admins, and interoperability so teams keep working whether they’ve switched or not.

The interoperability half

People keep working in Office while you migrate

Gmail + Docs

Edit Office attachments in place

Office Editing Mode in Gmail (GA later this quarter) opens attachments in Sheets, Docs, or Slides; when you’re done, Gmail drafts a reply with the updated file attached — no download/rename/re-upload loop.

Google Meet

Run on existing Cisco rooms

A native Meet experience lands on Cisco hardware before year-end — a no-cost hardware path that pairs Cisco AI Director and noise removal with Gemini in Meet, while keeping Webex, Teams, and Zoom reachable.

The through-line: a cutover doesn’t have to be a hard switch. Files stay editable across both worlds, and meeting rooms don’t get thrown out — which is what makes a phased migration realistic.

The security path

↻ The point: no manual re-classification, and encrypted content never travels unprotected end to end.

For the Excel crowd, Sheets closes specific gaps: high-fidelity pivot tables preserve grouped fields on import, combo and multi-X scatter charts come across with zero formatting loss and custom web fonts, and a new manual-calculation setting lets power users pause recalculation to batch edits, stabilize simulations, and run heavy financial models without interruption. Docs adds Tables of Captions (beta) that round-trip as Word’s Tables of Figures.

Where to start

Head to the Admin console to evaluate the data import tool, and test MIP-label mapping and encrypted-email handling before setting a cutover date. In the meantime, you can already edit Office files directly in Workspace — no license or file conversion required — so teams can start living in both worlds today.
