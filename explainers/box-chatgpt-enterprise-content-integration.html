Box Content, Now Inside ChatGPT

Box and OpenAI put enterprise content inside ChatGPT: browse your Box folders, @mention files as chat context, preview sources beside the conversation, and edit Box Notes — all while existing Box permissions and admin-controlled MCP tools decide what’s reachable.

The idea in five lines

  • Box files in the chat — browse your Box folder hierarchy and @mention files as context without leaving ChatGPT.
  • Preview and edit in place — see source files alongside the conversation and edit Box Notes without switching apps.
  • Permissions still rule — existing Box permissions decide which files are available; admins control which MCP server tools and actions users can invoke.
  • No content duplication — files stay secured and managed in Box while becoming usable across ChatGPT workflows.
  • Live now — generally available for all Box customers, rolling out to ChatGPT paid tiers over the following days.
So what for you

This is the pattern to watch for any AI-plus-content integration: the content stays in its governed system of record and the AI reaches in under existing permissions. When you evaluate one, confirm it enforces your source-system access controls rather than copying files into a new, ungoverned store.

Why it matters

The file never leaves its governed home

The usual way to get enterprise content into an AI tool is to copy or upload it — which spawns ungoverned duplicates. This integration inverts that: Box stays the system of record, and ChatGPT reaches into it live, so files remain secured and managed in Box while becoming usable in the chat.

Existing Box permissions continue to determine which files and folders are available, while Box admins control which MCP server tools and actions users can invoke.

The control plane

Two controls that keep it enterprise-safe

Access

Box permissions enforced

Which files and folders are reachable is decided by the permissions already set in Box — not re-granted in ChatGPT.

Actions

Admin-scoped MCP tools

Box admins choose which MCP server tools and actions users can invoke, bounding what the integration can do.

Early use cases span clinical researchers synthesizing studies, financial analysts reviewing performance, and legal professionals examining agreements — each reaching relevant Box content directly in ChatGPT.

Evaluating AI-plus-content integrations

Ask one question first: does the AI honor the access controls of your system of record, or does it copy content into a new store? Integrations that reach in under existing permissions keep governance intact; the ones that duplicate create the next data-sprawl problem.
