Production agents that operate software

Computer use, the Skills API, and the Files API are now generally available on the Claude Platform. Together they let you build agents that click through software they can see, apply your team’s expertise, and hand back finished files.

The idea in five lines

  • Three building blocks, now GA — computer use (operate software from screenshots), the Skills API (your expertise as loadable folders), and the Files API (documents in and out).
  • A new browser use tool reads the structure of a web page, so an agent targets a specific field or button rather than a pixel position — more reliable web automation.
  • Multi-action turns let computer use take several actions per model call instead of one, so tasks finish in fewer calls and less time.
  • Skills run in Claude’s sandbox — upload and version your own folders of instructions and scripts, attach them to any request, nothing for you to host.
  • Files API scales up — automatic expiration, 5× higher rate limits, and 1 TB storage per organization; reference a file by ID instead of re-sending it.
So what for you

If a workflow is stuck because a key system has no clean API, an agent can now drive its UI the way a person would. Pick one narrow, high-friction task — a portal submission, a claims step — and measure calls, cost, and completion on a pilot before you widen the deployment.

What each piece does

Operate, apply expertise, return files

Computer use lets an agent work in applications never built for automation: given a screenshot, it clicks, types, and scrolls like someone at the keyboard. The new browser use tool extends that to the web, reading page structure alongside the screenshot so it acts on the right element. The Skills API gives the agent your know-how — a skill is a folder of instructions, scripts, and templates Claude loads only when a task needs it — and the Files API is where documents live: upload a PDF or spreadsheet once, reference it by ID, and download whatever the agent produces.

A claims agent reads the intake file, follows a skill that encodes the team’s filing procedure, completes the submission in an insurer’s web portal, and saves the confirmation back as a file.

What changed at GA

The specifics worth knowing

Computer use Multi-action turns + HIPAA

Claude can take several actions per turn instead of one per model call, so tasks finish in fewer calls and less time. Computer use is now eligible for HIPAA-regulated workloads under Anthropic’s BAA.

Browser use Page structure, not just pixels

New in computer use today. It uses the same multi-action turns and adds page structure, so agents target web elements more reliably than with pixel positions alone.

Skills API Upload & version

A simpler API for uploading and versioning your own skills. They run in Claude’s code execution sandbox, so there is nothing for you to host.

Files API Bigger limits

Automatic file expiration, 5× higher rate limits, and 1 TB of storage per organization — upload once, reference by ID in later requests.
