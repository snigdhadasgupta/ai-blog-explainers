How Cresta Built an Agent Builder on the Claude Agent SDK

Cresta spent years turning contact-center transcripts into customer-experience AI. Its new move: wrap that expertise in Conductor, a natural-language builder that lets teams describe an agent in plain English and ship it to production — using the Claude Agent SDK as the harness.

The idea in five lines

  • CX expertise, productized — Cresta turned years of contact-center know-how into Conductor, a natural-language builder that stands up production customer agents.
  • Built on the Agent SDK — what began as an internal tool on Claude Sonnet and Opus became a customer-facing product once the Claude Agent SDK gave it a programmatic harness.
  • Half the deployment time — Conductor cut the time to stand up a new agent by roughly 50% in early use cases.
  • A meta-agent that learns — every build captures patterns and business rules as reusable skills, balancing flexible model behavior against hardened, deterministic workflows.
  • The build is 20% of the work — Cresta treats the first draft as a fifth of the effort and spends the rest on evaluation, testing, and optimization.
So what for you

If you’re turning an internal AI tool into a product, separate what is genuinely yours — your data and domain expertise — from the off-the-shelf harness, and budget most of your effort for evaluation and iteration, not the first working build. The demo is the easy 20%.

From internal tool to product

The hard part of a customer agent isn’t the chat

An agent handling real customer interactions has to navigate messy context: a caller asks for a refund without naming the purchase, reports two problems at once, or wants a return outside the policy window. To act, the agent needs purchase history, refund rules, account data, and payment status — stitched together reliably. Cresta, founded in 2017 and now at $100M+ ARR serving United Airlines, CVS Health, and Marriott, built Conductor so teams can encode that business context in natural language instead of hand-building each agent from scratch.

“The Claude Agent SDK gave us a way to use that same agentic development harness programmatically.” — Renjie Li, Engineering Lead, Cresta

What Cresta learned

Principles worth stealing

Design

Flexibility vs. determinism

Let the model adapt where judgment helps, but harden the enterprise-critical workflows into deterministic paths. Decide which is which before you ship — and re-test with every new Claude model launch to catch improvements and regressions.

Build

Dogfood, then draw the line

Cresta ran Conductor internally before releasing it, and kept a clear line between its proprietary edge — conversation data and CX expertise — and off-the-shelf components like the Agent SDK. “Anthropic gives us a strong, general-purpose foundation for agentic software development,” says VP of Engineering Xiangru Chen.

If you’re building your own agent builder

Start by mapping which workflows must be deterministic and which can flex, invest in an evaluation harness before scaling, and keep a sharp boundary between your proprietary data and the general-purpose foundation underneath. Plan for the first build to be the small part of the job.
