Building Commerce Agents With Claude

Anthropic is launching an open blueprint for commerce agents — the harnesses, patterns, and guardrails an engineering team needs to stand up a shopping agent and a merchant agent in days. Retailers running shopping agents on Claude have seen carts up to 35% larger and shoppers 60% more likely to complete a purchase.

The idea in five lines

  • An open blueprint, not a product — a public repository of working shopping and merchant agents with the harnesses, patterns, and guardrails to get running in days, plus a Claude Code plugin to start.
  • Real outcomes already — retailers running shopping agents on Claude report carts up to 35% larger and shoppers 60% more likely to complete a purchase.
  • The shopping agent lives in your app, assembles multi-item orders in conversation, remembers preferences, shows products and the cart inline, and answers order and return questions — leaving payment to you.
  • The merchant agent answers sales questions, flags inventory risks, and drafts promotions and campaigns from the store’s own data, with a person approving anything before it goes live.
  • Deploys where you already build — the Claude API, Amazon Bedrock, Microsoft Foundry, or Google Cloud Vertex AI, with partners like Accenture, Mastercard, and Visa enabling merchant communities.
So what for you

If commerce is on your roadmap for the holiday season, you no longer start from a blank repository. Fork the reference implementation, run the self-guided demo before writing code, then use Claude Code to fit it to your catalog, policies, and brand — the guardrails that constrain prices to real catalog data come built in.

What shipped

Two working agents you can run before writing code

The repository contains complete implementations of a shopping agent and a merchant agent that can be built on the Messages API, the Agent SDK, or Claude Managed Agents. You can see them running in a self-guided demo, then work with Claude Code to customize them to your catalogs, policies, and brand. Reference implementations cover retail, travel, telecom, and ticketing platforms.

Shopping agent

Lives in your app or website

A customer says “I need a tent, sleeping bag, and stove for a weekend trip with two kids,” and the agent searches the catalog, assembles the multi-item order, remembers preferences, shows products and the cart in the conversation, hands off to checkout, and answers returns and refund questions — without sending the shopper to a support page. Guardrails constrain prices and products to real catalog data and avoid manipulative upsell patterns.

Merchant agent

Supports the people running the store

A user asks “what should we discount to clear last season’s inventory?” and gets an answer from their own data. It reports what is selling, flags an item about to sell out before a promotion, recommends pricing from sales history, and drafts campaigns to move stock. When it proposes a change, a person approves it before anything goes live.

Why it matters

Trust is the currency of agentic commerce

Companies serving shoppers, travelers, subscribers, and merchants are already building on Claude, and the blueprint bakes in the practices they arrived at independently — tool-iteration limits, prompt caching, and keeping the person in control of anything irreversible. The consistent theme from payment networks and platforms is that agents raise the stakes on trust: merchants want control over how AI engages their customers, and the blueprint pairs Claude’s reasoning with the approval flows and payment infrastructure businesses already rely on.

“Our engineers had both commerce agents running locally in well under an hour, with live conversations working on the first attempt.” — Fetch

Priceline built the latest generation of its Penny assistant on Claude because a trip — flights, hotels, cars, dozens of options — is exactly the kind of multi-step reasoning the models are good at. Shopify is building a reference storefront that connects merchants’ stores through Catalog, UCP, and Shop Sign-in. Zomato’s engineers recognized the blueprint’s baked-in practices from building their own agent, and expect teams standing up their first agent to skip weeks of trial and error.

Under the hood

Guardrails and deployment are decided for you

Guardrails

Grounded in real catalog data

The shopping agent is constrained to actual catalog prices and products and avoids manipulative upsell patterns; the merchant agent stages changes for human approval. Safety is enforced in the harness, not just the prompt.

Deploy anywhere

Where you already build

Run on the Claude API, Amazon Bedrock, Microsoft Foundry, or Google Cloud Vertex AI. A Claude Code plugin gets a team started, and ecosystem partners help take it to production.

Partners

Payments and services included

Accenture, Mastercard, and Visa are working with Anthropic to enable clients and merchant communities to build on the blueprint, combining Claude with trusted payments and commerce infrastructure.
