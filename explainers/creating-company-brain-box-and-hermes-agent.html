A Company Brain for Agents: Box + Hermes

Agents need a governed place to read, act, and save their work. Box’s official skill now ships preinstalled with every Hermes Agent — turning enterprise content into a “company brain” while keeping every action inside the connected user’s existing permissions.

The idea in five lines

  • Agents need a file system — a governed place to read, act, and save — and Box is now that layer for Nous Research’s Hermes Agent.
  • Preinstalled by default — the official Box skill ships with every new Hermes install, teaching it to use the Box CLI, raw requests, and official SDKs.
  • Permissions stay intact — the agent acts as the connected Box user over OAuth, so it only sees and changes what that person already can.
  • Grounded, cited answers — a curated Box Hub becomes the source of truth and Box AI cites the source for every material claim.
  • Safe by construction — the skill verifies the user, prefers item IDs, asks before destructive changes, and reads each write back to confirm it.
So what for you

If your teams are wiring up agents, the hard part isn’t the model — it’s giving it memory it is allowed to use. Point agents at a governed content store that already enforces your permissions, rather than copying files into a side database the agent reads with unchecked access.

Why agents need a content layer

An agent is only as safe as the files it can reach

An autonomous agent is not much use until it has somewhere it can read, act, and save work — and that store has to respect who is allowed to see what. Box is positioning its platform as exactly that layer, and it has partnered with Nous Research so the official Box skill now ships with every new install of the Hermes Agent.

A Hermes “skill” is a set of operating instructions that teaches the agent how to do a class of work. The Box skill teaches Hermes to reach for the right Box interface for the job — the Box CLI for everyday content work, a raw box request when there is no dedicated command, and an official SDK when a developer is building an application. Hermes can install the CLI when it is missing and walk the user through connecting their account over OAuth.

The pitch: turn an organization’s existing content into a company brain for agents, without loosening the permissions that already govern it.

What the skill does

One skill, the whole Box surface

Content ops

Files, folders & versions

Manage uploads and file versions, move and organize content, and process approved batches with confirmation and verification built in.

Retrieval

Search, extract & metadata

Search content, pull structured data out of documents, and read or write metadata — the connective tissue for downstream automation.

Grounding

Box AI & Hubs

Ask cross-document questions and generate grounded, cited text against a curated Hub instead of the open web or the model’s memory.

Build

Apps, webhooks & events

Scaffold Box-backed applications, wire up webhook and event handlers, and pick the right official SDK when moving from prototype to product.

Crucially, the skill also carries the operational habits that a one-off integration usually skips: it verifies the current Box user before acting, prefers stable item IDs over reconstructed file paths, keeps command output narrow, asks before any permission change or destructive operation, and reads each write back as the same user to confirm the result actually landed.

How it works

From a governed Hub to a cited briefing

Figure 1 · A renewal copilot, end to end — source of truth to saved artifact
1

Curate the Hub

Put the approved source documents in a Box Hub and let Box index them as the single source of truth.

2

Verify identity

The agent confirms which Box user is active and that it can see the Hub and its files — before touching anything.

3

Ask, with citations

Box AI answers across the Hub’s documents and cites the source for every material claim, flagging gaps and conflicts.

4

Save back to Box

The finished brief is written back as a Box Note, added to the Hub, and re-read to verify it and its membership.

↻ Everything runs inside the connected user’s permissions; Box AI reasons over the Hub without downloading the source files for separate processing.

In Box’s worked example, an account team builds a “renewal copilot” over a Customer 360 Hub. The agent is told to treat the Hub as the source of truth, cite every important claim, flag missing or conflicting evidence instead of guessing, and confirm consequential changes — then it turns that grounded analysis into a concise, reusable renewal brief.

Beyond the demo

Other workflows on the same rails

Policy Q&A

Grounded answers

Explain an employee policy or contract term with citations drawn from an approved Box Hub, not the open model.

Extract

Fields into metadata

Pull structured fields out of files, write them to Box metadata, and verify each value before moving on.

Review

Contract vs. playbook

Compare agreements against an approved legal playbook and surface the clauses that need a human’s attention.

One caution worth keeping. An answer or Box Note can still contain sensitive information even though access stays bounded by the connected user’s permissions. Box’s guidance is to use fictional data for any public demo and to follow normal content-handling rules for real workflows — the guardrail is the identity boundary, not the model.
