A Marketer’s Weekly Sales Briefing, Rebuilt in an Hour

Adam Ward on Anthropic’s marketing team turned a manual Sunday-night slide ritual into a personalized Monday briefing sent to every account executive he supports — built in a one-hour hackathon with Claude Code, and no code of his own.

So what for you

The problem

From a Sunday slide deck to a system

Every marketer knows the hallway moment: a sales rep says “I never heard about that event” and you realize the latest work never reached the field. Ward’s first fix was the familiar one — a 15-minute Monday stand-up, fed by a Sunday evening spent collating updates into slides. As the team grew and he supported more sales segments, the ritual stopped scaling, and he no longer had time to pick out the right opportunities for each team.

What he wanted was a better product for each rep: a weekly digest tailored to their accounts and matched to everything marketing had going on. A one-hour slot in a marketing hackathon — dedicated time to rebuild repeatable workflows with Claude Code — was enough to get the first version working.

My approach is to open by telling Claude that although I’m not technical, I have this specific challenge — and to treat me as a product manager who deeply understands the business problem.

What made it useful

User feedback is the real prompt engineering

Ward piloted with a single 10-person sales team that agreed to give feedback — small enough that errors weren’t daunting. Each correction became an explicit rule, and the fixes tell you where these systems actually break.

Fix 1

Never invent a URL

When an event had no link in the source sheet, Claude composed a plausible one that led nowhere. The rule: a link renders only if the address matches the source character-for-character — and linkless events get dropped as noise.

Fix 2

Match content to the reader

A workshop for knowledge workers was recommended to an engineering VP. Now contact titles are checked against an event’s intended audience, and an industry gate keeps retail accounts off finance-dinner invitations.

Fix 3

Read the header, not column C

The events sheet was rearranged three times in six weeks. So each run now begins by reading the header row and verifying the column map — “look at the column with the event URL,” not “look at Column C.”

Duplicating the digest for a new team took a single field change: BDRs map to accounts through a different CRM relationship than account reps, so the prompt structure and content rules carried over unchanged and the BDRs were live within two days. The same pattern now serves customer success and alliances.

Where to start

Pick the repetitive task you spend the most hands-on time on and ask Claude to rebuild it — you’ll judge the output because you already know what good looks like. Write instructions like you’d brief a new colleague, version each change, pilot with a small committed group, and turn every correction into an explicit rule.
