# AI Blog Explainers — working notes

Static site, no build step. `index.html` is the landing page; the daily pipeline appends to the
`POSTS` array near the bottom of it, and the weekly task refreshes `this-week.html`.

## Do not remove when editing or regenerating index.html

These live in `index.html` and are **not** generated by the pipeline. A previous scheduled run
rewrote the page from an older copy and deleted them, which took the launch video off the live
site until it was restored by hand.

- **The hero launch video.** Marked with `<!-- LAUNCH VIDEO ... -->` / `<!-- /LAUNCH VIDEO -->`
  inside `.herogrid`, plus its CSS (`.herogrid`, `.herofilm`, and the `max-width:920px` media
  query). The hero is a two-column grid: copy left, player right.
- **The `.gitignore` entries under `video/`** (`assets/`, `probe/`, `score.wav`, `stats.js`).
  These are generated artifacts; without the entries they get committed.

When regenerating or reformatting `index.html`, edit it in place rather than rewriting it from a
stored template, and diff before committing — the page carries hand-made sections the template
does not know about.

## The launch video

Lives in `video/`, documented in `video/README.md`. Rendered from HTML by stepping a timeline in
headless Chromium; the score is synthesized by `video/score.py`. Nothing about it is manual, so
it can always be rebuilt:

```bash
node video/capture.mjs && python3 video/score.py && node video/render.mjs
```

The on-screen stats are read off this repo's own `POSTS` array by `video/stats.mjs` at render
time and shown as "N+", so they do not go stale as posts are added. Don't hard-code a count back
into `video/launch.html`.
