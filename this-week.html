A tampered Claude Code extension briefly appeared in the Cursor marketplace. ClaudeAgents

Message Threads

A coding agent can fire hundreds of requests per session, each resending the full conversation. Message threads add one Messages API parameter so agents send only what's new per turn — cutting median time to first token by about 35% on 500k–1M-token requests, with token cost unchanged. In public beta on the Claude Platform, AWS, Microsoft Foundry, and Google Cloud.
