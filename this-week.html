ClaudeAgents

When to Fold Subagents Into the Main Loop

Anthropic's Applied AI team keeps finding a single agent with skills beats both a one-giant-prompt design and an orchestrator-with-subagents design on quality, cost, and latency. Keep subagents only for measurable context bloat, truly parallel work, or tool-selection conflicts; otherwise fold routers, planners, and domain agents back into one loop using progressive disclosure of skills and tools. Migrate by evidence - build a 10-example eval, fold in one subagent, keep it only if the folded version scores worse.
